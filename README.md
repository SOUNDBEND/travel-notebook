# 彎彎腰の旅手帳

靜態旅遊行程網站（單一 `index.html`）。

- 倉庫：https://github.com/SOUNDBEND/travel-notebook
- 預計網址：https://soundbend.github.io/travel-notebook/

## 第一次開啟 GitHub Pages

與 [FIX](https://soundbend.github.io/FIX/) 相同做法：

1. 開啟 [Settings → Pages](https://github.com/SOUNDBEND/travel-notebook/settings/pages)
2. Build and deployment → Source 選 **Deploy from a branch**
3. Branch 選 **main**，Folder 選 **/ (root)**，按 Save
4. 等 1–2 分鐘，再打開 https://soundbend.github.io/travel-notebook/

## 以後如何更新

改好 `index.html` 後推到 `main` 即可。或先更新 Google 行事曆，再請小秘書同步網站並推上去。
